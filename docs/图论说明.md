# 图论软件说明文档

## 一、软件功能

### c0a - CSV数据预处理工具

该工具用于处理和导入CSV格式的电气连接数据到MySQL数据库，为后续的图论分析做准备。

#### 主要功能

1. 数据导入
   - 支持选择CSV格式的连接数据文件
   - 自动跳过标题行和非设备数据
   - 将数据导入MySQL数据库的v_csv_raw表

2. FTID解析
   - 解析设备的完整标识符（FTID）
   - 提取功能（Function）、位置（Location）、设备（Device）和端子（Terminal）信息

3. 数据格式化处理
   - 处理括号和冒号的特殊情况
   - 处理包含"-A"的情况
   - 处理包含"-X"和多个冒号的情况
   - 处理包含"-D/-E/-G/-M/-U"的情况
   - 处理":-"的情况
   - 提取和更新设备和终端字段

#### 数据库表结构

v_csv_raw表包含以下字段：
- id：主键
- cnumber：连续编号
- s_raw：源端原始数据
- s_ftid：源端完整标识符
- s_function：源端功能
- s_location：源端位置
- s_device：源端设备
- s_terminal：源端端子
- t_raw：目标端原始数据
- t_ftid：目标端完整标识符
- t_function：目标端功能
- t_location：目标端位置
- t_device：目标端设备
- t_terminal：目标端端子
- color：连接颜色信息

### c0b - 数据库结构创建和规范化工具

该工具基于c0a处理的原始数据，创建标准化的数据库表结构并进行数据转换。

#### 主要功能

1. 创建三个核心数据表：
   - v_csv_device（设备表）：记录所有设备的基本信息
   - v_csv_devpoint（设备端点表）：记录所有设备端点信息
   - v_csv_conn（连接表）：记录设备间的连接关系

2. 数据表结构说明

a) v_csv_device 表：
```sql
CREATE TABLE v_csv_device (
    id INT NOT NULL AUTO_INCREMENT,
    fdid VARCHAR(255) NOT NULL,      -- 设备标识
    Function VARCHAR(255),           -- 功能
    Location VARCHAR(255),           -- 位置
    Device VARCHAR(255),             -- 设备名称
    isInPanel TINYINT(1) DEFAULT 1,  -- 是否在面板中
    Type VARCHAR(50),                -- 设备类型
    isSim TINYINT(1) DEFAULT 0,      -- 是否为仿真设备
    isPLC TINYINT(1) DEFAULT 0,      -- 是否为PLC
    isTerminal TINYINT(1) DEFAULT 0, -- 是否为端子
    project_id VARCHAR(255)          -- 项目ID
)
```

b) v_csv_devpoint 表：
```sql
CREATE TABLE v_csv_devpoint (
    id INT NOT NULL AUTO_INCREMENT,
    raw VARCHAR(255) NOT NULL,        -- 原始数据
    ftid VARCHAR(255) NOT NULL,       -- 完整标识
    belongtoDevice VARCHAR(255),      -- 所属设备
    Function VARCHAR(255),            -- 功能
    Location VARCHAR(255),            -- 位置
    Device VARCHAR(255),              -- 设备
    Terminal VARCHAR(255),            -- 端子
    Type VARCHAR(50),                 -- 类型
    voltage DOUBLE DEFAULT 0,         -- 电压
    current DOUBLE DEFAULT 0,         -- 电流
    resistance DOUBLE DEFAULT 0,      -- 电阻
    isInPanel TINYINT(1) DEFAULT 0,   -- 是否在面板中
    isSocket TINYINT(1) DEFAULT 0,    -- 是否为插座
    isSetPoint TINYINT(1) DEFAULT 0,  -- 是否为设定点
    isSensePoint TINYINT(1) DEFAULT 0, -- 是否为感应点
    project_id VARCHAR(255)           -- 项目ID
)
```

c) v_csv_conn 表：
```sql
CREATE TABLE v_csv_conn (
    id INT NOT NULL AUTO_INCREMENT,
    connNo VARCHAR(255) NOT NULL,     -- 连接编号
    source VARCHAR(255) NOT NULL,     -- 源端点
    target VARCHAR(255) NOT NULL,     -- 目标端点
    color VARCHAR(50),                -- 颜色
    isCable TINYINT(1) DEFAULT 0,     -- 是否为电缆
    isInPanel TINYINT(1) DEFAULT 0,   -- 是否在面板中
    connType VARCHAR(50),             -- 连接类型
    voltage DOUBLE DEFAULT 0,         -- 电压
    current DOUBLE DEFAULT 0,         -- 电流
    resistance DOUBLE DEFAULT 0,      -- 电阻
    project_id VARCHAR(255)           -- 项目ID
)
```

3. 数据处理流程
   - 导入设备基本信息
   - 提取和导入设备端点数据
   - 建立设备间的连接关系
   - 支持项目ID区分不同项目

4. 数据导入规则
   - 仅处理K1.%位置的设备和连接
   - 自动过滤无效数据
   - 去除重复记录
   - 保持数据完整性

#### 使用方法

1. 确保已通过c0a处理原始数据
2. 运行c0b.bat
3. 输入项目ID（默认：EOS1550）
4. 等待数据处理完成

#### 技术特点

1. 数据完整性管理
   - 唯一键约束
   - 索引优化
   - 事务处理

2. 性能优化
   - 批量数据处理
   - 索引支持
   - 优化的SQL语句

3. 可维护性
   - 清晰的表结构
   - 完整的日志记录
   - 数据验证机制

### c0c - 设备内部连接创建工具

该工具用于创建设备内部的连接关系，主要处理K类（继电器）、Q类（接触器）和S类设备的内部端子连接。通过读取v_csv_devpoint表中的设备端点数据，创建设备内部端子之间的连接关系。

#### 主要功能

1. 创建v_csv_innerconn表
   - 读取v_csv_devpoint表中的设备端点数据
   - 记录设备内部端子之间的连接关系
   - 支持多种连接类型（如线圈、常开、常闭等）
   - 记录连接的电气特性（电压、电流、阻值等）

2. 设备类型识别和处理
   - 从v_csv_devpoint表识别不同类型设备（K、Q、S类）
   - 特别处理KS安全继电器的特征（如S11-S12, S21-S22端子对）
   - 根据设备类型应用不同的连接规则

3. 内部连接创建规则
   - 自动识别设备端子对
   - 创建标准连接（如线圈A1-A2）
   - 创建常开/常闭触点连接
   - 根据设备特征创建特殊连接

4. 数据处理能力
   - 支持批量处理多个设备
   - 自动跳过不符合条件的设备
   - 提供详细的处理日志
   - 显示处理统计信息

#### v_csv_innerconn表结构
```sql
CREATE TABLE v_csv_innerconn (
    id INT NOT NULL AUTO_INCREMENT,
    connNo VARCHAR(255) NOT NULL,     -- 连接编号
    source VARCHAR(255) NOT NULL,     -- 源端点
    target VARCHAR(255) NOT NULL,     -- 目标端点
    color VARCHAR(50),                -- 颜色
    isCable TINYINT(1) DEFAULT 0,     -- 是否为电缆
    isInPanel TINYINT(1) DEFAULT 0,   -- 是否在面板中
    connType VARCHAR(50),             -- 连接类型
    voltage DOUBLE DEFAULT 0,         -- 电压
    current DOUBLE DEFAULT 0,         -- 电流
    resistance DOUBLE DEFAULT 0,      -- 电阻
    PRIMARY KEY (id),
    INDEX idx_source (source),
    INDEX idx_target (target)
)
```

#### 使用方法

1. 确保已运行c0a和c0b完成基础数据处理，并且v_csv_devpoint表中包含有效的设备端点数据
2. 运行c0c.bat
3. 程序将自动处理所有符合条件的设备
4. 查看日志了解处理结果

#### 技术特点

1. 智能设备识别
   - 基于设备名称的类型识别
   - 基于端子特征的设备特性识别
   - 灵活的规则匹配系统

2. 自动化处理
   - 自动创建必要的数据表
   - 自动清理历史数据
   - 批量处理设备连接

3. 详细的处理记录
   - 记录每个设备的处理过程
   - 统计处理结果
   - 支持问题追踪和验证
